# منشطات الإباضة — موشن جرافيك (9:16، 60 ثانية)

فيديو توعوي عمودي (1080×1920، 60fps) بنص باللهجة العراقية عن مخاطر أخذ منشطات الإباضة بدون إشراف طبي.

| الملف | الوظيفة |
| --- | --- |
| `ovulation-stimulants.mp4` | الفيديو النهائي مع الصوت |
| `index.html` | التكوين الكامل: كل إطار دالة نقية للزمن `render(t)`، مع مشغّل للمعاينة (مسافة = تشغيل، ←/→ ثانية، `,` `.` إطار) |
| `synth.mjs` | الموسيقى والمؤثرات الصوتية مولّدة برمجياً ومتزامنة مع نفس التوقيتات ← `soundtrack.wav` |
| `render.mjs` | يرندر الإطارات في Chromium ويجمعها بـ ffmpeg |
| `fonts/` | خط Alexandria (OFL) |

## المشاهد

| الوقت | المشهد | الفكرة البصرية |
| --- | --- | --- |
| 0–8 | السؤال | محادثة دردشة، شريط حبوب، اختبار حمل يظهر خطّه الثاني |
| 8–17 | لا! | مسح دائري من فقاعة الجواب، «لا!» بارتداد نابضي واهتزاز، «كوارث» بتشويش رقمي |
| 17–33 | متلازمة فرط تنشيط المبيض | مبيض تتكاثر فيه الجريبات وينتفخ (فلتر goo)، ثم ثلاث أعراض بأيقونات متحركة |
| 33–40 | حمل متعدد | خط تخطيط القلب يتحول لانتقال، خلايا تنقسم ١→٤ بنبضات غير متزامنة |
| 40–46 | اللي ناسب صديقتج | شاشة مقسومة: نفس الحبة، نتيجتان مختلفتان |
| 46–60 | على قياسج | شريط قياس خياطة يمسح المشهد، خياطة تُرسم حول النص، ختم «وبس.» |

## إعادة البناء

```sh
node synth.mjs                # soundtrack.wav
node render.mjs stills 8.3,20 # لقطات للمراجعة في out/
node render.mjs video 60 4    # out/video.mp4 (60fps، 4 عمليات متوازية)
```

يتطلب Node 18+ و Playwright (Chromium) و ffmpeg.
